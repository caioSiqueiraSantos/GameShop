## 2. Algoritmos Implementados

### Algoritmo Principal — BFS (Busca em Largura)

| Campo | Resposta |
|-------|----------|
| Nome do algoritmo | Busca em Largura (BFS) |
| Arquivo de implementação | src/algorithms/bfs.ts |
| Complexidade de tempo | O(V + E) |
| Complexidade de espaço | O(V) |

**Funcionamento:** A partir do usuário selecionado, o BFS percorre o grafo de amizades até profundidade 2, coletando usuários que são amigos dos amigos mas sem conexão direta. Os candidatos são rankeados pela quantidade de amigos em comum.

```typescript
export function suggestFriends(graph: Graph, userId: string): FriendSuggestion[] {
  const directFriends = new Set(graph.neighbors(userId))
  const suggestions = new Map<string, string[]>()

  for (const friend of directFriends) {
    for (const candidate of graph.neighbors(friend)) {
      if (candidate === userId || directFriends.has(candidate)) continue
      if (!suggestions.has(candidate)) suggestions.set(candidate, [])
      suggestions.get(candidate)!.push(friend)
    }
  }

  return Array.from(suggestions.entries())
    .map(([id, mutualFriends]) => ({ userId: id, mutualFriends }))
    .sort((a, b) => b.mutualFriends.length - a.mutualFriends.length)
}
```

### Algoritmo Adicional — Similaridade de Jaccard

| Campo | Resposta |
|-------|----------|
| Nome do algoritmo | Filtragem Colaborativa (Jaccard) |
| Arquivo de implementação | src/algorithms/jaccard.ts |
| Complexidade de tempo | O(N · g), onde N = usuários, g = tamanho médio da biblioteca |
| Complexidade de espaço | O(N) |

**Fórmula:**

```
sim(u, v) = |Biblioteca(u) ∩ Biblioteca(v)| / |Biblioteca(u) ∪ Biblioteca(v)|
```

```typescript
export function jaccard(a: Set<string>, b: Set<string>): number {
  if (a.size === 0 && b.size === 0) return 0
  const intersection = [...a].filter(x => b.has(x)).length
  const union = new Set([...a, ...b]).size
  return intersection / union
}
```

## 4. Telas do MVP

### Tela de Entrada — Login Verossímil & Acesso Rápido

Tela inicial com formulário de autenticação verossímil contendo usuário/e-mail, senha com alternância de visibilidade, validações, feedback explicativo e acesso rápido aos 8 perfis de demonstração (todos com senha padrão `admin123`). Ao logar, o sistema valida as credenciais e redireciona para a loja.

### Tela de Resultado — Loja com Recomendações

Exibe a seção "Recomendado para você" com jogos sugeridos via BFS (amigos que jogam) e Jaccard (perfil similar). Cada card exibe a razão da recomendação. Abaixo, o catálogo completo.

### Tela de Biblioteca

Exibe a coleção de jogos adquiridos pelo usuário, com filtros dinâmicos por categoria, busca interna e estatísticas de gêneros favoritos.

### Tela de Amigos & Comunidade

Exibe as conexões diretas do usuário no grafo, sugestões de amizade geradas pelo BFS (com indicação de amigos em comum), e barra de pesquisa dinâmica para encontrar qualquer usuário armazenado no LocalStorage com opção de adicionar ou desfazer conexões.

### Tela de Detalhe do Jogo

Capa, descrição, preço e quem na rede do usuário já possui o jogo.

### Painel Admin

Cadastro de novos jogos com upload de capa, lista de jogos cadastrados e gerador de dados aleatórios.
